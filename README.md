# Oneten Digital Media - One-Page Website

A fully responsive, modern one-page website for Oneten Digital Media - a leading digital marketing agency in Chennai.

## 🚀 Features

- **Responsive Design**: Mobile-first approach with seamless experience across all devices
- **Hero Slider**: Animated sliding banner with smooth transitions
- **WhatsApp Integration**: Floating WhatsApp button for instant customer communication
- **SEO Optimized**: Complete meta tags, Open Graph, and semantic HTML structure
- **Modern UI/UX**: Clean, professional design with smooth animations
- **Contact Form**: Interactive contact form with WhatsApp integration
- **Google Maps**: Embedded map showing business location
- **Performance Optimized**: Fast loading with optimized CSS and JavaScript

## 📁 Project Structure

